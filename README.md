# Maître des mots ! — retrouver et écrire les mots sans les recopier

Jeu en ligne pour le cycle 2 (CE1), conçu par une enseignante pour sa classe.
L'élève lit ou écoute une devinette, une image ou une question, puis **écrit le mot en entier**, avec ses accents, et reçoit une correction immédiate.

## Intentions pédagogiques

Les mots travaillés sont ceux des dictées de la période, regroupés par **graphème ou difficulté** (B et D, M et N, AN AM EN EM, accents…). Le jeu sert trois apprentissages, réunis dans chaque carte :

| | ✍️ Orthographe lexicale | 🖊️ Production d'écrit | 👂 Compréhension |
|---|---|---|---|
| **Objectif** | Fixer les lettres muettes, les doubles lettres, les accents, les mots invariables | Écrire le mot en entier, sans modèle sous les yeux | Relier un sens (définition, phrase, image) à une forme écrite |
| **Ce qu'on attend de l'élève** | Justesse | Justesse, accents compris | Comprendre pour retrouver |
| **Chronomètre** | Non | Non | Non |

### Pourquoi retrouver plutôt que relire ?

Retrouver un mot en mémoire, puis recevoir la correction, fixe l'orthographe plus durablement que le relire (effet de test : Roediger & Karpicke, 2006 ; Karpicke & Roediger, 2008). Revenir sur les mêmes mots à intervalles espacés renforce l'effet (Cepeda et al., 2006, 2008). C'est le principe du jeu : un rappel actif, répété sur les mots de la période.

Maître des mots **complète** les dictées et les mots appris à la maison : il ne les remplace pas.

## Ce que le jeu fait pour l'apprentissage

**Des devinettes qui ne trahissent pas le mot.**
Chaque devinette suit la même structure : une définition courte, une phrase-exemple où le mot est masqué par `[…]`, puis au besoin un indice sur la difficulté orthographique (« J'ai un E à la fin qui fait sonner ma consonne »). Le mot n'apparaît jamais dans les indices, ni dans ceux des autres cartes de la séance.

**Des pièges qui visent les vraies erreurs.**
Après une erreur, la carte montre la bonne réponse et le piège à retenir (« s muet », « n devant b, m, p devient m »…), pour comprendre l'erreur et pas seulement la voir corrigée.

**Plusieurs façons d'interroger le même mot.**
Devinette, choix entre plusieurs orthographes, vrai ou faux, image : le mot est rencontré sous des formes différentes, ce qui évite le simple par-cœur d'une carte.

**Les mots ratés reviennent.**
La liste des mots à revoir s'affiche en fin de partie, pour les rejouer.

**Des lots alignés sur les devoirs.**
Chaque carte appartient à un lot qui suit la progression des mots donnés à apprendre. L'élève peut ne rejouer que les mots de la semaine, ou tout mélanger.

**Une lecture à voix haute.**
Les consignes peuvent être lues par la synthèse vocale du navigateur, pour les élèves qui lisent encore difficilement.

## Types de cartes

| Type | Principe |
|---|---|
| **Devinette** | « Qui suis-je ? » : l'élève lit ou écoute les indices et écrit le mot. |
| **Choix** | Plusieurs orthographes sont proposées : l'élève choisit la bonne. |
| **Vrai ou faux** | Une affirmation sur le mot (lettre muette, invariabilité…) à valider. |
| **Image** | Une illustration à nommer, puis à écrire. |

**Réglages** (enregistrés sur l'appareil) : lecture vocale, types de cartes, filtre par lot, accents obligatoires ou non, lettres accentuées affichées.

## Le générateur

[`generateur_maitre_des_mots.html`](https://eautsu.github.io/maitre_des_mots/enseignants/generateur_maitre_des_mots.html) est un outil **pour les enseignants**, utilisable dans le navigateur, sans serveur. Il permet de :

- **créer une nouvelle séance** : titre, cartes (type, devinette, réponse, lot, image, piège) ;
- **ouvrir un jeu existant** (par exemple l'une des onze séances ci-dessus) pour ajouter, modifier ou supprimer des cartes ;
- **télécharger le jeu** obtenu, une page HTML autonome prête à être utilisée.

Les onze séances servent d'**exemples de référence** : ouvrez-en une dans le générateur pour voir comment les devinettes sont construites, puis modifiez-la ou repartez de zéro. Les images sont à ajouter dans un dossier `images/` à côté du jeu (noms attendus dans [`images/README.md`](images/README.md)).

## Limites connues

- Aucun suivi n'est conservé : pas de vue d'ensemble de la classe, pas de score enregistré.
- Pas d'adaptation automatique : c'est l'enseignant qui choisit la séance et le lot.
- La qualité de la lecture vocale dépend des voix installées sur l'appareil.
- Les images doivent être déposées dans `images/` ; sans elles, un espace réservé s'affiche et le jeu reste jouable.
- Le jeu n'a pas fait l'objet d'une évaluation de son efficacité en classe.
